## 2024-03-01 - Avoid toISOString() for Local Dates
**Learning:** Using `new Date().toISOString().split('T')[0]` inside tight React component loops and data processors is very slow (~4x slower) than manually formatting the string using `.getFullYear()`, `.getMonth()`, and `.getDate()`. It also causes subtle off-by-one errors due to time zones when you really want the user's *local* date (as it defaults to UTC).
**Action:** Always format dates manually using string template literals with `.padStart()` for local dates when iterating over loops, especially in performance-sensitive logic like data grids.
